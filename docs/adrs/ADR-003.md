# ADR-003: Paperclip-native execution supersedes repo-native agent workers

- **Date:** 2026-08-22
- **Status:** Accepted (founder-directed)
- **Context:** The original plan (PBIs 007–018) implemented the 10 Hermes workers as repo-native Node modules with mocked gates, intending a future worker container to execute them on crons. Meanwhile Paperclip was deployed live (`paperclip.kcb.ma`), the founder onboarded a CEO account, and OpenRouter was wired via env (`OPENAI_API_KEY`/`OPENAI_BASE_URL`). Founder directed: "plan the complete implementation of the SWE Drip autonomous company in the deployed Paperclip under a new organization created from scratch" with a Fourthwall-native store driven by Fourthwall MCP (`https://mcp.fourthwall.com`, OAuth).
- **Decision:**
  - Execution substrate for all 11 agents is **Paperclip**: agents are hired in the org `SWE Drip` by pasting SOUL.md identities materialized at `agents/souls/*.md`; Paperclip owns orchestration, crons, budgets, task board.
  - Repo remains source of truth for: SOUL.md content, specs, brand/storefront contracts, `program.md` memory, provider/config libraries (`agents/lib/*`, used by future tooling and verification), deterministic gates.
  - PBIs **007–018 are superseded** (not deleted): their behavior contracts (scoring rubric, ≤6-word slogans, FLUX prompts, kill/scale rules, 4:1 ratio, report formats) are absorbed into the SOUL.md content and Paperclip configuration of PBIs 020–027. Files remain as reference.
  - Store is **Fourthwall-hosted**; Paperclip agents operate it via Fourthwall MCP tools (`ecommerce_*`, `brand_*`) after one-time OAuth login by founder.
- **Consequences:**
  - Faster path to a running company (no worker container to build/operate).
  - Repo test suite keeps guarding contracts it can see offline (souls lint, schemas, provider shapes); runtime behavior verification moves to Paperclip task evidence (screenshots/task outputs) — manual-sort reviews.
  - If Paperclip proves insufficient later (API limits, cron fidelity), repo-native execution can be revived from these same specs without redesign.
- **Alternatives considered:** Repo-native worker container (PBIs 007–018 as written) — deferred, not discarded.

References: `specs/paperclip-org/spec.md`, `specs/fourthwall-store/spec.md`, `plans/README.md` Phase 7.
