# ADR-001: Onboard docs-only repo to ASDLC

- **Date:** 2026-08-22
- **Status:** Accepted
- **Context:** Repo at `KCB/SWE-DRIP` contained only `README.md` + 7 `docs/` playbooks describing target SWE Drip system (Hetzner CX31 + Coolify + Paperclip + OpenRouter + Fourthwall). No `AGENTS.md`, no `specs/`, no `plans/`, no tests, no git worktree, no ASDLC binding. No runtime code exists — `docs/` is the only truth.
- **Decision:**
  - Initialize git worktree (`git init`), preserve no legacy history (none existed), start micro-commit discipline.
  - Bind to Plane `kcb/SWDR (2af62f36-c11a-411a-89b5-8e5a5176b829)` verified live via MCP `plane-kcb` — persist as `Plane workspace: kcb` / `Plane project: 2af62f36-c11a-411a-89b5-8e5a5176b829` in `AGENTS.md` and `plans/README.md`.
  - Establish verification baseline with Node 22 + `node:test`: `tests/smoke.test.js` (8 docs-contract invarian tests), `scripts/lint.js` (markdown contracts), `package.json` scripts (`build`/`lint`/`test`/`verify`). No external deps.
  - Create `AGENTS.md` with constitution, gate commands (with Windows `cmd /c` note), conventions (no change without spec, brand invariants, budget discipline), workflow, and §5 Context Map (YAML `project_structure` + `documentation_index`).
  - Create `ARCHITECTURE.md` as as-built snapshot (marked "not gospel", changeable via ADR), describing current modules, boundaries, target data flow, and known constraints.
  - Bootstrap `plans/README.md` (sequencing + Plane sync) and `plans/PROGRESS.md` (append-only log), empty `specs/`/`tasks/` awaiting `asdlc-plan`.
  - Records: `.gitignore`, this ADR.
- **Consequences:**
  - Repo is now indistinguishable from a greenfield ASDLC repo; `asdlc-plan` → `asdlc-execute` loop is unblocked.
  - All future changes (including one-line fixes) require a human-reviewed spec in `specs/{feature}/spec.md` or compact behavior contract before code (Spec Reversing gate).
  - Deterministic gates (`npm run verify`) must pass before any PBI moves to In Review.
  - `Backlog` Plane status remains ignored; only `Todo` is synced.
- **Alternatives considered:** Defer git/tests until first code PBI — rejected (Ralph Loop requires runnable gate before any PBI).
- **Verification:** `npm run build` PASS, `npm run lint` PASS, `npm test` 8/8 PASS, Plane binding live-verified.

References: `AGENTS.md:1-2` (Plane binding), `AGENTS.md:2` (gates), `ARCHITECTURE.md:1` (as-built marker), `plans/README.md:5` (Plane sync).
