# ADR-001 — Onboarding bootstrap: clean-room V1 implementation

- **Status:** Accepted
- **Date:** 2026-09-13
- **Deciders:** Founder

## Context

The SWE Drip program has a POC (`kcbdev/SWE-DRIP-POC`, local `C:\Users\kcb19\Work\KCB\SWE-DRIP`) built on Paperclip + Hermes. The v1.0 Product Vision (`docs/swe-drip-product-vision-v1.md` §3.1) retires Paperclip/Hermes from the core product pipeline and rebuilds it as a custom LangGraph `StateGraph` with a Postgres checkpointer. A complete v1.0 spec kit (vision, definition, PRD, UX, technical, data/API/LLM, delivery/acceptance) was authored and placed in this new repo. The repo started with docs only: no git history, no ASDLC structure, no gates, no Plane binding.

Onboarding into ASDLC requires a single verified Plane binding, a runnable deterministic gate, and the constitution/architecture/planning artifacts before any feature work starts.

## Decision

1. **Clean-room V1 is the implementation of record.** The POC is retired as a runtime for the core pipeline; its repo remains published as `kcbdev/SWE-DRIP-POC`. The V1 repo (`kcbdev/SWE-DRIP`) is where all new work lands.
2. **POC is reference-only.** When planning/documenting/implementing hits a gap or needs a decision, the POC may be consulted; nothing (code, schemas, configs) is applied without human validation, and findings are recorded in the relevant spec/PBI with the validation outcome.
3. **Plane binding:** `kcb / SWDRP` — project `SWE DRIP`, id `d162b6d4-1205-4eea-9ef3-871354c5e8a3` (new project, distinct from the POC's `kcb/SWDR`). Verified live via MCP `plane-kcb` on 2026-09-13. Sync is strictly scoped to this project; `Backlog` ignored until `Todo`.
4. **Verification baseline:** zero-dependency Node 22 + `node:test` docs-contract gates now (`npm run verify` = build + lint + test). Every app-stack PBI must extend these gates (Next.js build/test, pytest) and update `AGENTS.md` §2 — the docs checks remain as a regression gate.
5. **Target stack** (per the v1 spec kit, no new decisions hidden here): Next.js 15 + shadcn/ui Control Panel, FastAPI API, Postgres (LangGraph checkpointer + audit + users), LangGraph pipeline, Fourthwall MCP reads / pipeline-owned writes, OpenRouter per-node model routing, existing Coolify/Hetzner infra.

## Alternatives considered

- **Continue the POC repo / Paperclip runtime** — rejected: gateway model-override bug, Paperclip coupling, and the vision doc's explicit retirement decision.
- **Bind V1 to the existing POC Plane project `kcb/SWDR`** — rejected: clean separation between the retired POC's history (32 closed issues) and V1's delivery phases; the founder created `SWDRP` for V1 instead.
- **Wait for the app scaffold before standing up gates** — rejected: no PBI may start without a runnable gate; docs-contract gates are runnable today and evolve with the stack.

## Consequences

- `asdlc-plan` / `asdlc-execute` can run immediately; both resolve the binding from `AGENTS.md` top lines.
- The docs-contract lint/test suite becomes a permanent regression gate — weakening it is a defect.
- The POC's `In Review` Plane state does not exist in `SWDRP` yet; it is added during onboarding so execution sorting has its target state.
- Any future structural change (repo layout, stack substitution, gate replacement) requires a new ADR and an `AGENTS.md` §5 Context Map update.
