# ADR-002: Coolify application `swedrip` on `kcb` — Docker + domain + env + volume reservations

- **Date:** 2026-08-22
- **Status:** Accepted (provisioned via Coolify API `vfsgl47pv5ew2hbrqxbjwmjq`)
- **Context:** `specs/coolify-deploy/spec.md` Decision-1..4 + `docs/04-deploy.md` Day 1 topology (Hetzner CX31 → Coolify `:8000`/`:443` → Traefik → app `:3000`/`80` → volumes). Server `kcb.ma server` (`e4cowswcks844wow04c084wg`, `host.docker.internal`, wildcard `https://kcb.ma`) is Coolify host (verified `GET /api/v1/servers` → 3 servers, `kcb.ma server` is `is_coolify_host:true`). Project `swe-drip` (`vztwc3dxianozufxinxm0cgp`, env `production` `r5c2ohxgtq9irlvjiwbtzji1`) created 2026-08-22 via `POST /api/v1/projects`.
- **Decision:**
  - **Image:** `nginx:alpine` runtime from `Dockerfile:1` (multi-stage `node:22-alpine` builder) — per `specs/coolify-deploy` Decision-1 static nginx keeps image <50MB and deploys without Paperclip. Future PBIs may swap to Node SSR without changing plumbing.
  - **App:** `swedrip` (`vfsgl47pv5ew2hbrqxbjwmjq`) — `POST /api/v1/applications/public` with `project_uuid=vztwc…`, `server_uuid=e4cows…`, `environment_uuid=r5c2…`, `destination_uuid=i448wgc…` (StandaloneDocker `coolify` on `kcb`), `git_repository=https://github.com/KCB/SWE-DRIP`, `git_branch=master`, `build_pack=dockerfile`, `ports_exposes=80`, `domains=https://swedrip.kcb.ma`, `dockerfile_location=/Dockerfile`. Build pack `dockerfile` (not `dockercompose`/`nixpacks`), port `80` (nginx), Traefik Let's Encrypt via `domains` field.
  - **Health:** `PATCH /api/v1/applications/vfsgl…` → `health_check_enabled:true`, `path=/health`, `port=80`, `method=GET`, `scheme=http`, `return_code=200`, `interval=30`, `timeout=5`, `retries=3`, `start_period=10` — matches `nginx.conf:1` `location = /health` + `Dockerfile:1` `HEALTHCHECK CMD wget -qO- http://localhost/health`.
  - **Volumes (reserved, not yet mounted):** `paperclip-data:/app/data`, `paperclip-workspace:/workspace` — declared in `.coolify/app.json` as future Paperclip named volumes (`docs/04-deploy.md:1.6` `/app/data` + `/workspace`). Not attached in this PBI to avoid mount failure before Paperclip PBI lands — `Coolify → swedrip → Storages` will add them then. Names are identical so later PBI attaches without rename.
  - **Env vars (catalog, values stay in Coolify Secrets UI):** `OPENROUTER_API_KEY` (≡ `OPENAI_API_KEY` + `OPENAI_BASE_URL=https://openrouter.ai/api/v1`, `DEFAULT_MODEL=anthropic/claude-sonnet-4-6`), `OPENAI_API_KEY`, `OPENAI_BASE_URL`, `DEFAULT_MODEL`, `WORKSPACE_PATH=/workspace`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `FOURTHWALL_MCP_TOKEN`, `LOOPS_API_KEY`, `BUFFER_ACCESS_TOKEN`, `PLANE_API_KEY` — per `docs/02-stack.md` table. All marked `Secret` where `docs/02-stack.md` says Secret. No `Build Variable` unless explicitly documented (these are runtime). Redeploy preserves them.
  - **Domain/TLS placeholder:** `domains` set to `https://swedrip.kcb.ma` at creation — full TLS issuance/redirect is PBI-003's verification (expected `http→301→https`, LE cert, `strict-transport-security` if Traefik HSTS). DNS `swedrip.kcb.ma` already resolves `158.220.96.44` (wildcard `*.kcb.ma` → `kcb` server, verified `dns.lookup`).
  - **Git vs Registry:** Git-direct (`KCB/SWE-DRIP#master`) preferred (no registry secret) — Q3 answer. Requires `git push` of local `master` (`c9e3872` etc.) to `https://github.com/KCB/SWE-DRIP` before first `Deploy` succeeds; if repo private, attach Deploy Key or GH App (flow per `docs/02-stack`). Registry mode not used in this PBI.
- **Consequences:**
  - `GET /api/v1/applications/vfsgl…` → `health_check_enabled:true` `health_check_path:/health` `fqdn:https://swedrip.kcb.ma` `git_repository:KCB/SWE-DRIP` `build_pack:dockerfile` `ports_exposes:80` — PBI-002 verification.
  - `GET /api/v1/servers/e4cows…/resources` will list `swedrip` after first deploy; `Coolify UI → swe-drip → swedrip → Deployments` shows build log with `FROM node:22-alpine` → `FROM nginx:alpine` + `nginx -t` OK.
  - `swedrip.kcb.ma` remains NXDOMAIN/`404` until PBI-003 verifies http→https + LE, but Traefik route is declared.
  - Volumes stay unmounted until Paperclip PBI — no data loss risk (only `GET` not yet `Storages`).
- **Alternatives considered:** `dockercompose` build pack with `compose.yaml` — rejected (adds compose parsing version 5, not needed for static nginx). `nixpacks` — would hide `Dockerfile` and break `<50MB` guarantee. Separate Coolify host vs `kcb.ma server` — chosen `kcb.ma server` is the Coolify host itself (where Traefik runs), matching `swedrip.kcb.ma` wildcard.
- **Verification:** `GET /api/v1/applications/vfsgl47pv5ew2hbrqxbjwmjq` after PATCH → health true, `GET /api/v1/projects/vztwc…` + `GET /api/v1/servers/e4cows…` — live via `coolify.kcb.ma` API with `COOLIFY_ACCESS_TOKEN`.
