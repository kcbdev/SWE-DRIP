# Brand Identity

## Mission

The only clothing brand that makes software engineers feel seen — not patronized.

## Target customer

- US / UK / EU software engineers
- $80k–$200k household income
- Buys merch as identity signal
- Active on Reddit (r/ProgrammerHumor, r/cscareerquestions, r/webdev), HN, Twitter/X
- Gifting occasions: birthday, new job, "I survived the incident", white elephant
- Discovery: Etsy search, Twitter, Reddit, newsletter recommendations

---

## Positioning

Not generic "programmer merch". Hyper-specific SWE subculture — the kind only a working engineer
gets instantly. Exclusivity through specificity. The brand tweets like a senior SWE with
15 years of production scars, not like a company.

**Competitive gap**: most dev merch is cringe stereotypes or generic coffee-and-code content.
The authentic SWE culture layer — git crimes, incident PTSD, stack tribalism, 3am deploys —
is almost completely uncovered.

**Our edge as a developer-founder**: custom storefront fast, agent pipeline for A/B at scale,
features no Etsy shop or TeePublic seller can match.

---

## Voice

- Insider. Dry. Never tries too hard.
- The brand talks like a staff engineer who's seen things.
- Earned humor only — no setup/punchline structure.
- Never explains the joke. If it needs explaining, it's not a design.
- Test: "Would an actual SWE DM this to their team chat?" If yes, ship it.

## Aesthetic constants

| Element | Value | Notes |
|---|---|---|
| Background (primary) | `#0D0D0D` | Void black |
| Accent (primary) | `#00FF41` | Terminal green |
| Accent (secondary) | `#FF6B35` | Error orange |
| Clean option | `#FFFFFF` | For light colorways only |
| Font (display) | JetBrains Mono Bold | First choice |
| Font (fallback) | Fira Code, Courier New | Same mono vibe |
| Style | Terminal output formatting | No gradients, no shadows, no decorative effects |
| Finish | High contrast, flat | Looks like a terminal, not a poster |

**Anti-patterns — never use:**
- Gradients or drop shadows
- Pastel or rainbow color schemes
- Cartoon characters or illustrations (unless terminal-rendered ASCII art)
- Generic coffee/keyboard iconography
- Motivational quotes or hustle culture framing

---

## Design philosophy — three modes

Every winning design hits one of these:

1. **Insider recognition** — only a dev gets it instantly. No explanation needed.
   Example: `exit 0` printed as a tombstone epitaph.

2. **Cathartic dark humor** — "this is my actual life and it hurts".
   Example: "3am and the PR is still open" in PagerDuty alert styling.

3. **Aesthetic flex** — looks visually clean AND carries a subtle dev signal.
   Example: `undefined behavior` in minimal sans-serif, ambiguous to outsiders.

## Highest-converting themes

| Theme | Examples | Why it works |
|---|---|---|
| Terminal / CLI output | `sudo make me a sandwich`, exit codes, man pages | Literal aesthetic match |
| Git crimes | `git push --force (and pray)`, `git blame` as life philosophy | Universal shared trauma |
| Debugging despair | "It works on my machine™", "3am and the PR is still open" | Cathartic |
| Stack tribalism | Rust evangelism, Python indentation wars, JS fatigue | Tribal buyers = repeat purchase |
| CS fundamentals humor | Big O on grocery lists, off-by-one birthday cards | Niche, highly shareable |
| Incident culture | "I survived the great Kubernetes migration", on-call PTSD | Strong gifting intent |
| Corporate dev life | JIRA ticket aesthetic, "requirements changed again" | Shared misery = community |

**Low signal — avoid:**
- Generic "I love coffee and code"
- Anything a non-developer would understand immediately
- Long sentences (readability at small print sizes breaks)
- Anything adjacent to political content

## Validation process before designing

Run this before spending design compute (FLUX credits):

1. **Reddit signal** — post the phrase as plain text on r/ProgrammerHumor.
   Threshold: >100 upvotes in 24h = green light. Under 50 = kill.

2. **Twitter/X signal** — tweet the phrase with no image.
   Threshold: >50 likes in 24h from devs = green light.

3. **Fourthwall / TeePublic dupe check** — search for exact phrase.
   Already saturated = skip, or find a variant angle.

Only design after passing at least one signal check.
