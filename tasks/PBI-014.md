# PBI-014: Nodes 9-11 — Fourthwall create (DRAFT-only), publish gate, shelf pricing

## Directive

Implement nodes 9–11: `pipeline/nodes/fw_create.py` (calls Fourthwall through an injected client interface; in this phase it may only create DRAFT/unpublished products — a live call sits behind an explicit flag and is mocked in tests; never sets `PUBLIC`), `pipeline/nodes/publish_gate.py` (`interrupt()` before any PUBLIC transition; config flag controls whether the gate is active), `pipeline/nodes/shelf.py` (mechanical price-invariant check $32 tee/$62 hoodie/$20 mug; collection assignment requires an active, non-retired contract; rejects the run on mismatch). Extend `pipeline/graph.py` wiring. Tests: shelf rejects wrong price and retired/missing contract; publish gate interrupts; fw_create cannot emit PUBLIC state; mock client captures the exact draft payload.

Scope boundaries: no live Fourthwall write path and no publish cutover (fourthwall-integration spec, Phase 5); no MCP client here (the injected interface is implemented by the fourthwall spec's client).
