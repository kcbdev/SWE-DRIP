# PBI-001: Containerize repo — multi-stage Dockerfile + static nginx

## Directive
Build a production-ready container image for this docs-only repo so Coolify (server `kcb`) can deploy it without rebuilding logic. Create a multi-stage `Dockerfile` (node:22-alpine builder → nginx:alpine runtime), an `nginx.conf` that serves the static site + `GET /health` → `{"status":"ok"}`, a `.dockerignore`, and a local smoke helper. The image must build from clean checkout, run non-root, be < 50 MB compressed, expose `80`, and not embed any secret values. Do not touch Coolify app provisioning or domain config — that's later PBIs.
