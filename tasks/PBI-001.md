# PBI-001: Scaffold Control Panel — Next.js 15 + shadcn/ui + brand shell

## Directive

Create `control-panel/` as a Next.js 15 (App Router, TypeScript) application with shadcn/ui and Tailwind initialized, dark-theme only, carrying the SWE Drip brand tokens (`#0D0D0D` background, `#00FF41` accent, JetBrains Mono for data/mono content, a humanist sans for prose). Ship a minimal shell: root layout, a placeholder Dashboard page, and one vitest smoke test asserting the brand tokens are wired. Also write `docs/adrs/ADR-002.md` recording the repo layout and single-deployable pipeline decision.

Scope boundaries: no auth, no data fetching, no feature screens — shell only. Do not touch `api/`, `pipeline/`, root `package.json`, or the existing docs gates.

## Context

- Spec: `specs/app-foundation/spec.md`
- Depends on: none
- Files/modules touched: `control-panel/**` (new app, package.json, next.config.ts, tsconfig.json, app/layout.tsx, app/page.tsx, app/globals.css, components/ui/*, lib/utils.ts, vitest config + test), `docs/adrs/ADR-002.md`
- Plane: (pending sync)

## Verification

- Contracts C1 (Control Panel side), C2 of the spec.
- Executable: from `control-panel/`: `cmd /c "npm install"` then `cmd /c "npm run build"` (exit 0) and `cmd /c "npm run test"` (vitest, brand-token test passes).
- Manual check: page renders void black with terminal-green accent; no gradients/shadows/pills.

## Refinement rule

- If Next.js 15 or shadcn defaults diverge from the spec (e.g. Tailwind major version), keep the brand contracts (C2) intact and note the divergence in the PBI resolution — do not silently substitute another UI kit.
- Any structural change beyond `control-panel/` (new top-level dirs) requires updating ADR-002 before proceeding.
