# PBI-009: Design Agent — FLUX.2 Pro (OpenRouter) + Fourthwall MCP publish

## Directive
Implement the critical-path Design Agent (`agents/design/`) that renders a print-safe PNG via `black-forest-labs/flux.2-pro` on OpenRouter `POST https://openrouter.ai/api/v1/images` (2048×2048, prompt: `Minimalist apparel design. Typography: JetBrains Mono Bold. Text: "[SLOGAN]". Color: Terminal green #00FF41 on void black #0D0D0D. Centered isolated. No decorations. No gradients. Print-safe flat.`), falls back once to `google/gemini-3.1-flash-image` with fallback prompt `Large bold white monospace text "..." centred on solid black background. No graphics. No decorations. Clean readable high-contrast. Simple typographic. Screen-print ready.` on 429/5xx, saves `/workspace/designs/[brief_id].png` (validate RGB not RGBA, <10MB, ≤2048), then calls Fourthwall MCP `ecommerce_generate-product-design-previews` → preview URL + `ecommerce_create-offers-from-designs` → offer id + live product, writes `product_url` back into `workspace/listing_copy.json[0].product_url`, on double failure calls Telegram `notify_founder` (mocked). Do not mutate Listing — only PNG + product_url.
