# PBI-009: Dashboard UI

## Directive

Replace the placeholder Dashboard page with the real screen: top row stat cards (runs awaiting approval with link to Approvals; monthly spend progress bar vs $130 cap with amber warning above 80%; active collections count with at-risk flag), middle activity feed (last N events, relative timestamps, entity links), right rail pending-approvals top list with a "View all" link. Explicit empty/error states for every card and the feed. Data exclusively from `GET /api/dashboard/summary`.

Scope boundaries: read-only; no approval actions inline (Approvals screen owns them); no KPI charts. Do not modify the API from PBI-008 except if a rendering need exposes a contract gap — record it instead.
