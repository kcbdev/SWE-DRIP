# PBI-031: Analytics KPI API + dashboards

## Directive

Implement `api/app/analytics.py` (KPI math: units, conversion, windowed aggregation, threshold comparison) and `api/app/routers/analytics.py`: `GET /api/analytics/collections/{id}` (KPI time series vs that contract's `kpi_thresholds`, Viewer+), `GET /api/analytics/overview` (revenue vs break-even line, Viewer+), and `GET /api/analytics/collections/{id}/recommendation` (retirement recommendation data — produced only at/after `eval_window_days` below threshold, never auto-executed). Build the Analytics screen: per-collection KPI dashboard with threshold marks and the overall revenue chart; surface the recommendation as a banner linking to the collections retire flow. Data sourced from Fourthwall reads + contract YAML via the collections store.

Scope boundaries: no retire action here (collections UI owns it); no writes to Fourthwall; no duplicate order storage.
