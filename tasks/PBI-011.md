# PBI-011: Social Agent — cron + 4:1 ratio + Buffer scheduling

## Directive
Implement the Social Agent (`agents/social/`) that posts 3×/week without burning karma. Cron `0 11 * * TUE,WED,THU` (11am ET) with rotation `TUE: new design drop (image + minimal copy, link in reply only)`, `WED: dev meme/culture (no product)`, `THU: engagement poll/question`; enforce 4 value:1 promo ratio persisted in `workspace/social_state.json` (valueCount/promoCount, assert `promo*4 <= value`), consume `workspace/listing_copy.json.product_url` + `ecommerce_list-offers` product image/URL for TUE only, schedule via `POST https://api.bufferapp.com/1/updates/create` (`BUFFER_ACCESS_TOKEN`), Twitter guard plain text first + link only in reply thread if >50 likes, Reddit guard `never link in post body` (link in comment reply only if >100 upvotes), hashtags 0 on Twitter. Do not mutate Video/Community.
