# PBI-005: Workspace file contracts + seed — design_briefs / listing_copy schemas

## Directive
Define and enforce the shared I/O contracts that every agent reads/writes: `workspace/design_briefs.json` and `workspace/listing_copy.json` via JSON schemas, plus the idempotent seed helper. Create `schemas/design_brief.schema.json` (Trend brief: phrase, source_url, score 0–100, score_breakdown {engagement 0–40, novelty 0–30, specificity 0–30}, rationale, suggested_aesthetic terminal|minimal|dark-humor, flag nullable; array wrapper) and `schemas/listing_copy.schema.json` (Copy output: brief_id, primary_slogan ≤6w, slogan_variants[3], fw_title ≤60, fw_description 150–200w, fw_tags 13, product_types, product_url nullable), create `workspace/` sim dir + fixtures, and `scripts/seed-workspace.js` that `mkdir -p workspace/designs workspace/reports && echo "[]" > workspace/design_briefs.json if missing` and exits 0 when files already exist. Do not mutate Dockerfile/nginx/domain — only workspace/schemas.
