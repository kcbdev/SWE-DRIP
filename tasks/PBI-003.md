# PBI-003: Polyglot gates + local dev harness

## Directive

Extend the root verification chain so `cmd /c "npm run verify"` runs the docs gates **and** the two stack gates: Control Panel build/test and pytest (offline, no DB). Add `docker-compose.yml` (pgvector-capable Postgres 17, `db` service) and root `.env.example` listing every required variable with placeholders. Update `AGENTS.md` §2 (commands/baseline) and §5 Context Map (mark `control-panel/`, `api/`, `pipeline/`, `collections/` live). Extend `scripts/lint.js` only additively (e.g. verify chain checks, `.env.example` presence) — never weaken existing docs-contract checks.

Scope boundaries: no application features; do not change the docs smoke assertions; do not add CI/deployment.

## Context

- Spec: `specs/app-foundation/spec.md`
- Depends on: PBI-001, PBI-002
- Files/modules touched: `package.json` (root), `scripts/lint.js`, `docker-compose.yml`, `.env.example`, `AGENTS.md`
- Plane: kcb/SWDRP-3

## Verification

- Contracts C4, C5, C6 of the spec.
- Executable: `cmd /c "npm run verify"` green end-to-end (docs + web + api); `docker compose config` exits 0; `scripts/lint.js` secret scan green with no real secrets in `.env.example`.
- Manual: `docker compose up -d db` then `docker compose ps` shows the db healthy (not required for the gate itself).

## Refinement rule

- If a stack gate cannot run in this Windows environment (e.g. vitest/jest mismatch), stop and record the blocker with the exact error — do not remove the gate from the chain to make `verify` pass.
- Context Map updates must reflect real paths; if a path differs from ADR-002, update ADR-002 first.
