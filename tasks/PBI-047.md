# PBI-047: Operator token management UI (settings block + client config)

## Directive

Make token issuance usable without curl, in the style of the existing
settings sections:

1. `control-panel/lib/operator-tokens.ts` (new) — `fetchTokens()`,
   `issueToken(name, scopes)`, `revokeToken(id)` via `apiFetch`, with
   `OperatorToken` / `IssuedToken` types (metadata only, plus the once-only
   `token` on issuance).
2. `control-panel/components/settings/operator-tokens.tsx` (new, admin-only
   section): token table (name, prefix, scopes, created_by, revoked,
   last_used, created — never values); issue form (name + read/operate
   scope radio with one-line explanations); the issued value displayed once
   with a copy button and a dismiss that clears it from state (never
   refetched — the list endpoint never returns values); revoke behind a
   confirm; a client-config snippet (streamable-http URL derived from the
   API base + Authorization header) with a copy button. Non-admins render
   nothing — the API remains the enforcement point.
3. Mount the section in `control-panel/app/settings/page.tsx`.
4. Tests: lib helpers (paths/methods/bodies) + component (admin list
   without values, issue-once display + copy, revoke confirm flow, viewer
   sees no section, issued value cleared on dismiss and absent from list
   payloads).

Scope boundaries: no backend changes (PBI-043 API is complete); no token
value in logs, errors, or test fixtures (use `sdr_test…` style inert
literals); no signup/invite flows.

- Spec: `specs/operator-mcp/spec.md` (C1 issuance UX, C5 secrets discipline)
- Depends on: PBI-043 (token API)

## Verification

- Contracts C1 (issuance UX) and C5 of the spec.
- Executable: `npx vitest run` green; `cmd /c "npm run verify"` green.
- Manual: as admin in Settings → issue `read` token → value shows once with copy → dismiss → list shows prefix only → revoke with confirm → row flagged revoked.

## Refinement rule

- If the section needs data the list endpoint does not return, extend the shared API shape (used by any future client) — never scrape it from the issued value.
