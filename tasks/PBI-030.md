# PBI-030: Catalog mirror API + Catalog screen

## Directive

Implement `GET /api/catalog` and `GET /api/catalog/{product_id}` (Viewer+) sourced through the Fourthwall MCP read client: product list/detail with server-computed price-invariant status ($32 tee / $62 hoodie / $20 mug pass/fail) and order history. Build the Catalog screen: product grid, product detail (variant info, invariant badge, order history), and explicit stale/error states when reads degrade. Read-only throughout.

Scope boundaries: no writes to Fourthwall; no KPI charts (PBI-031); no price computation client-side — the API flags invariant status; no product-create UI.
