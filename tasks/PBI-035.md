# PBI-035: HITL graduation review — decision record (A19, manual)

## Directive

Assemble and record the graduation decision package for each HITL gate (collection approval, design QC, publish gate): pull the calibration agreement stats (human vs rubric, A11 views), the publish-gate history (approvals, regenerations, post-publish issues), and incident notes; draft a per-gate recommendation (kept on / turned off) with the evidence minimums, observation window, and revert condition; founder signs; apply any "turned off" decision through the settings mechanism (audit row) and record the full decision in `plans/PROGRESS.md` (plus `docs/graduation-review-<date>.md` if it outgrows a table). Add read-only evidence queries only if existing views cannot produce the stats.

Scope boundaries: no threshold edits, no rubric-version changes, no calibration-data edits; the review does not re-run pipelines.

- Spec: `specs/hitl-graduation/spec.md`
- Depends on: PBI-033 (toggle mechanism), PBI-022 (calibration suite), PBI-027 (publish history), PBI-024 (calibration view)

- Plane: (pending sync)

## Verification

- Contracts C1–C5 of the spec.
- Executable: none required beyond existing gates; any read-only query added must keep `cmd /c "npm run verify"` green.
- Manual (founder): reviews the draft, signs the per-gate decision, and confirms that any toggle applied is config-only and revertible by config.

## Refinement rule

- If evidence minimums are unmet, the correct outcome is "kept on" — never graduate on partial data; record the gap and the next review trigger instead.
- The refusal to gather more data is itself a decision: record why the current evidence is sufficient when it is.
