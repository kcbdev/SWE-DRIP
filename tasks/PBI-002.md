# PBI-002: Scaffold API + pipeline packages — FastAPI health + LangGraph-ready

## Directive

Create the Python side of the monorepo as a single flat project: root `pyproject.toml` installing packages `api` and `pipeline`; `api/app/main.py` exposing `GET /api/health` returning `{"status":"ok"}`; `api/app/config.py` for env settings (pydantic-settings); `pipeline/` as an importable package placeholder. Declare dependencies now so later PBIs don't re-touch packaging: `fastapi`, `uvicorn`, `pydantic-settings`, `httpx`, `langgraph`, `langgraph-checkpoint-postgres`, `psycopg[binary]`, `sqlalchemy`, `alembic`, `sse-starlette`, `mcp`; dev extras: `pytest`, `pytest-asyncio`.

Scope boundaries: no business endpoints, no DB connection at import time, no pipeline nodes. The health endpoint must not require a database.

## Context

- Spec: `specs/app-foundation/spec.md`
- Depends on: none
- Files/modules touched: `pyproject.toml` (root, new), `api/__init__.py`, `api/app/__init__.py`, `api/app/main.py`, `api/app/config.py`, `api/tests/test_health.py`, `pipeline/__init__.py`
- Plane: kcb/SWDRP-2

## Verification

- Contracts C1 (api/pipeline side), C3 of the spec.
- Executable: `python -m pip install -e ".[dev]"`; `python -m pytest api/tests -q` green; `python -c "from api.app.main import app"` exit 0.
- Manual: `uvicorn api.app.main:app` + `curl /api/health` returns the exact JSON.

## Refinement rule

- If editable install of flat `api`/`pipeline` packages proves impossible with the chosen backend, adjust packaging mechanics only (keep `api.app.main:app` and `pipeline` import paths stable) and note it in the resolution.
- No feature code may be added to `main.py` beyond the health route.
