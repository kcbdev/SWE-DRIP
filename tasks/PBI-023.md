# PBI-023: Design detail + calibration API

## Directive

Implement `GET /api/designs/{id}` (Viewer+): render reference, four rubric scores + threshold + result + `rubric_version`, placement + contrast-valid colorways, and run context (brief, collection contract reference). Implement `GET /api/designs/{id}/calibration` returning the human decision(s) (from `hitl_approvals`) side-by-side with the rubric verdict, and `GET /api/calibration` (list, Viewer+) aggregating recent designs for the calibration indicator. Derive everything from the checkpointer state + decision records — no new store. Tests: detail shape from a fixture run state; calibration join with/without a decision; role gates.

Scope boundaries: no decision endpoints here (use the HITL decision API); no UI (PBI-024); no rubric changes.
