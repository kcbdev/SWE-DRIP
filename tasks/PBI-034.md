# PBI-034: Agents — roster, routing view, budget caps (FR-17)

## Directive

Implement `api/app/agents.py` (roster assembly: per-node role, model from `pipeline/routing.py`, budget cap + month-to-date spend rolled up from `model_calls`) and `api/app/routers/agents.py`: `GET /api/agents` (Viewer+) and `PATCH /api/agents/{id}/config` (Admin) accepting budget-cap changes only — required cost-impact note, cap validation against the global $130, audit row. Model routing is returned read-only with a `change_path` hint ("reviewed change to pipeline/routing.py"). Build the Agents screen: roster table (role, model, cap, spend with progress), detail view with recent runs links, and a budget-cap edit form requiring the cost-impact note; routing displayed read-only.

Scope boundaries: no runtime routing overrides (pipeline-core C3); no credential fields; no spend recalculation beyond the existing rollup.
