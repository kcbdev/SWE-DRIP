# PBI-046: Operator runbook + ADR-006 + live MCP smoke

## Directive

Make the doorway operable by a human and prove it live:

1. `docs/adrs/ADR-006.md` — the MCP doorway decision: FastMCP Streamable HTTP
   in-process at `/mcp`, scoped Bearer tokens (no OAuth/DCR — the ADR-005
   lesson), reads-mirror-REST, writes-reuse-services, graph inspection
   read-only with structural mutation out. Alternatives considered
   (stand-alone MCP process, OAuth) with reasons rejected.
2. `DEPLOY.md` — MCP section: token issuance (`POST /api/operator-tokens`),
   rotation/revocation procedure, client config snippet (Claude Code /
   Opencode MCP StdIO-vs-HTTP note: this server is remote HTTP), scope
   guidance (`read` for observers, `operate` for runners), and the secret
   handling rules (shown once, vaulted, never logged).
3. Live smoke (founder credentials, production): mount reachable at
   `https://swedrip-api.kcb.ma/mcp`; issue → read tool (`runs_list`,
   `graph_inspect`) → `operate` write probe (`agent_config` dry validation,
   e.g. dead-ID 422) → revoke → 401. Record evidence in `plans/PROGRESS.md`.
   No production run start in this PBI (spend + gates stay founder-driven).

Scope boundaries: no new tools or behavior (docs + live proof only); no
production run start; token values never enter the PROGRESS record or chat
beyond the issuance moment.
