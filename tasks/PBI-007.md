# PBI-007: Audit log viewer + export UI

## Directive

Build the Audit Log screen: a compact, filterable table (timestamp, actor, action, entity with type/id, before → after diff) with filters for actor, action type, entity, and date range, plus an export control that downloads the filtered set (CSV/JSON) from the API. Cross-link entity references to their detail screens when those exist; do not duplicate audit data into other screens.

Scope boundaries: reads only; no editing, no deletion, no retention controls. Do not touch the writer (PBI-006).
