# PBI-010: Pipeline state + graph skeleton + OpenRouter client + routing + cost logging

## Directive

Create the pipeline foundation: `pipeline/state.py` (typed run state carrying the design record), `pipeline/graph.py` (StateGraph assembly targeting the locked 11-node order; compiles and runs end-to-end with the nodes present so far), `pipeline/llm.py` (httpx-based OpenRouter client: chat, vision, image; injectable transport for tests; loud error when `OPENROUTER_API_KEY` is missing), `pipeline/routing.py` (the per-node model table from data spec §3), `pipeline/costs.py` (writes `{node, model, tokens_in, tokens_out, cost_usd}` to `model_calls`; table migration owned by PBI-008). Add a checkpointer factory: `MemorySaver` by default for tests, `AsyncPostgresSaver` when `DATABASE_URL` is set. Tests: graph compiles; client captures exact model params per call with a mocked transport; routing table covers all 11 nodes; cost writer payload shape.

Scope boundaries: no real node logic yet beyond what makes the graph run (only `pipeline/nodes/*` files created by their own PBIs may be wired in); do not add FW calls; no live network in tests.
