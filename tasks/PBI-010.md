# PBI-010: Listing Agent — price/tags/collection + live confirm

## Directive
Implement the Listing Agent (`agents/listing/`) that ensures every FW product is correctly priced/tagged/collectioned and visibly live. After Design Agent confirms product_url set, agent calls Fourthwall MCP `ecommerce_update-offer` (price exactly `$32 tee / $62 hoodie / $20 mug` per brand hard invariant), `ecommerce_list-collections` to assign correct collection (Terminal Collection vs Stack-Specific per slogan stack), set `fw_tags` (from listing_copy.json) and `fw_description`, `status:active`, then confirm `GET https://swedrip.fourthwall.com/products/[slug]` 200 (or `ecommerce_list-offers` shows active). Handles hoodie variant pricing only (no other changes). Do not mutate Design or Social.
