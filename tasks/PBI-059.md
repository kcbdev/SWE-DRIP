# PBI-059: Research output handoff (bug fix — board never displays)

## Symptom

Live run `rsch_cli-4808648812c8` rendered board v1, but the research UI
shows "No board yet". Root causes found 2026-09-17:

1. `assemble_draft` hardcodes `"mood_board": []` — the rendered board is
   never linked into the draft it was rendered for.
2. Nothing persists the approved draft anywhere: `contract_draft` writes
   state only ("PBI-020 owns persistence"), but no code path carries the
   state draft into the collections store. Approving the gate completes
   the run and strands the output in the checkpointer.

## Directive

1. `assemble_draft(..., board_ref=None)` — when given, `mood_board` is
   `[board_ref]` (schema-validated relative ref, as before). The
   `contract_draft` node passes the basename of the rendered board's
   `file_ref` (`board.png`, `board-r2.png`, …).
2. Research decide endpoint (`routers/research.py` only — no item-graph
   changes): after a successful `collection_gate` resume with approved
   True, upsert the candidate in the collections store from the run
   state — `gate_decision.edited_contract` when present, else
   `draft_contract` — then audit `research.handoff`. Rules:
   - status stays `draft`, identity (`collection_id`) never changes;
   - backfill: when the draft's `mood_board` is empty but state `board`
     has a `file_ref`, set `[basename]` (heals pre-fix runs like the
     live one above);
   - reject/regenerate persist nothing;
   - a persist failure after a successful resume is loud (500 + reason)
     — the draft remains recoverable in checkpointer state.
3. UI: the Mood board section additionally shows the selected run's
   board (derived relative ref) while the contract lists no refs, marked
   as in-flight. Pure helper + component test.

Scope boundaries: no item-graph changes; no schema changes (`mood_board`
already exists); no auto-approve and no direct-to-`active` writes (the
existing approve endpoint stays the activation path).

## Verification

- Executable: `python -m pytest api/tests pipeline/tests -q` green
