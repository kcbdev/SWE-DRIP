# PBI-006: Audit writer + read API

## Directive

Create the `audit_log` table (migration) and the single write path: `api/app/audit.py` exposing a writer helper/dependency that records `actor_user_id, timestamp, action, entity_type, entity_id, before_json, after_json`; add the read API `GET /api/audit` with filters (actor, action, entity type/id, date range) and an export variant (`format=csv|json`). Add the Better Auth server-side hook in `control-panel/` that writes login/logout rows to the same table (documented schema). Add tests: writer payload correctness, filter query building, role gate (Viewer+ read).

Scope boundaries: no UI (PBI-007); do not retrofit audit calls into endpoints that don't exist yet — the spec contract binds future PBIs to use the writer. No updates/deletes on `audit_log` anywhere.

- No endpoint added later may bypass the writer; CC-3 is checked at each phase.
