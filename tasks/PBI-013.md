# PBI-013: Community Agent — keyword monitor + SWE-voice replies

## Directive
Implement the Community Agent (`agents/community/`) that monitors brand mentions every 12h (`cron 0 */12 * * *`) via `twitter_api_v2` mentions/search + `reddit_api` keyword search for `swedrip, swe drip, software engineer shirt, programmer merch, developer shirt` plus slogan names from `listing_copy.json`, and replies in SWE brand voice matching the commenter's tone (sarcastic→dry, enthusiastic→warm), never including a product link unless `directlyAsked===true`, never arguing with criticism (acknowledge + move on), and appending every interaction to `workspace/community_log.json` `{timestamp, platform, keyword, original_id, reply, tone}` for pattern tracking. Do not mutate Social/Video.
