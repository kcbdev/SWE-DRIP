# PBI-012: Video Agent — Veo 3.1 Lite 8s async clip

## Directive
Implement the Video Agent (`agents/video/`) that creates 8 s product showcase clips 2×/week (Mon+Thu 10:00, orchestrator `claude-haiku-4-5` + generation `google/veo-3.1-lite` via OpenRouter `POST https://openrouter.ai/api/v1/videos` + poll `GET /videos/{job_id}` every 10s, 60 tries → 10m timeout). Prompt template `Terminal screen. Green text '[SLOGAN]' types character by character. T-shirt materialises. Dark cinematic. SWE aesthetic. 8 seconds. Ambient keyboard sounds.` consuming `product_image_url` from `ecommerce_list-offers` + `slogan` from `listing_copy.json`, writes clip URL to `workspace/reports/video_clips.json` for Social pickup, on timeout → notify CEO + skip product. Do not mutate Social/Community.
