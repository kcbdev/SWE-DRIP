# PBI-025: Fourthwall MCP read client

## Directive

Implement `api/app/fourthwall/client.py`: a typed read-only client over the official Fourthwall MCP server (Streamable HTTP, OAuth2 bearer from `FOURTHWALL_MCP_TOKEN`), exposing typed methods for product list/detail, orders, and analytics pulls; wire config through `api/app/config.py`; define a degraded-error model (timeouts/auth failures surface as explicit errors to callers, never silent empties). Tests use a mocked MCP transport; no live network in gates.

Scope boundaries: reads only — no write/create methods exist on this client; no UI; no catalog/analytics endpoints (later PBIs consume this).
