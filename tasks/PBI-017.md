# PBI-017: Storefront — Brutal theme CSS + pricing + SEO enforcement

## Directive
Make the Fourthwall storefront earn trust and index: apply Brutal theme by creating `storefront/brutal.css` with `:root { --color-background:#0D0D0D; --color-primary:#00FF41; --color-text:#FFFFFF; --font-display:'JetBrains Mono', monospace; }` (void black, terminal green, mono — no gradients/shadows/pastels/cartoons), extend `scripts/lint.js` `storefrontCssCheck()` to fail on gradient/shadow/pastel, extend storefront lint to assert any `ecommerce_update-offer` price fixture `===32||62||20` per tshirt/hoodie/mug invariant (smoke already asserts `$32/$62/$20` in `docs/01-brand.md`), and implement `selectTags()`/`buildFwTitle()` helpers enforcing title ≤60 with ≥2 keywords from primary/mid SEO tiers and tags 8–12 covering Tier1 2–3 + Tier2 3–4 + Tier3 4–5 (listing_copy.json schema allows 13 but live tags trim to 8–12). Verify Merchant-of-Record plumbing `ecommerce_get-payout-info` mocked non-empty. Do not mutate agent product publish logic.
