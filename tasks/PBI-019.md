# PBI-019: LLM provider config — Hermes agent registry + OpenRouter client layer

## Directive
Build the shared provider layer every Hermes worker imports: `agents/lib/config.js` (11-agent registry mirroring docs/03-agents.md roster — name, model, trigger, budget cap, output) and `agents/lib/provider.js` (OpenRouter client factory with `callLLM`/`generateImage`/`generateVideo` request builders; base URL from `OPENAI_BASE_URL` env default `https://openrouter.ai/api/v1`; auth from `OPENROUTER_API_KEY` || `OPENAI_API_KEY`). Missing key must throw a loud error naming exactly where the founder sets it (Paperclip UI env vars or Coolify → swedrip → Environment Variables) — never silently, never baked. Include `sumAgentSpend()` + `assertBudgetCap()` ($130/mo cap from workspace/reports/*.json). All network shapes mocked in tests per docs/02-stack.md samples. Do not implement any agent business logic — this is infrastructure only.
